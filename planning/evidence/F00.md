### 4a. QML suite: 8 failures (environment drift)

All eight are in `ui/tests/qml/tst_preview_on_cursor.qml`, class
`KeyboardReaderNavigation`, all `Compared values are not the same` where the
selected row id stays empty (`Actual ""` vs `Expected "m1"/"m2"/"m3"`). The list
model itself is not being applied (`MessageList.qml` logs
`Cannot read property 'm1' of undefined`), i.e. keyboard selection never takes
effect. The tree is pristine upstream, and CI runs Qt **6.8.3** while this laptop
has Qt **6.11.2**; a Qt keyboard/shortcut routing change is the likely cause.
CI's `portable-tests` job deliberately excludes `test-qml` ("Version-sensitive
QML/libcurl checks remain on the Omarchy host"), so this does not affect CI.
Classification requested from the supervisor: documented local-environment
limitation (Qt 6.11.2) rather than a code defect.

### 4b. Clippy: 3 errors (newer clippy lints)

Under Rust 1.98.1, on unmodified code:

- `src/providers/imap/read/search.rs:235` — `clippy::collapsible_if`
- `src/providers/imap/read/search.rs:694` — `clippy::collapsible_if`
- `src/mail/tests.rs:88` — `clippy::needless_return`

CI does **not** run clippy; its gates are `make test-rust test-js
test-shell-portable`, the API contract gates, and the standalone builds. Fixing
these means editing product code, which is outside F00's allowed changes.
Classification requested from the supervisor: a toolchain-drift lint failure to
be fixed in a future task, not a F00 regression.
