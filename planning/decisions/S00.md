## 2. Two Sonnet defects the adapter must not trip over

Both were confirmed against the installed 6.29.0 plugin and its source
(`src/quick/spellcheckhighlighter.cpp`).

### 2.1 `replaceWord` uses a stale word length (must prime with `suggestions`)

`replaceWord(replacement, at)` selects the word under `at` but then anchors the
replacement by `d->selectedWord.size()` — the word remembered by the last
`suggestions()` call — instead of the word it just selected. With no prior
`suggestions(at, …)` it inserts instead of replacing:

```
no prior suggestions:  replaceWord("word", 6)  ->  "ok 📨 wordwrod and …"   (inserted)
after suggestions(6):  replaceWord("word", 6)  ->  "ok 📨 word and …"        (replaced)
stale from another word: suggestions(3) then replaceWord(…, 10)  ->  corrupts a different word
```

**Frozen rule:** the adapter calls `suggestions(position, 0)` and
`replaceWord(replacement, position)` as one indivisible step for the same
position. `suggestions(position, 0)` primes the length without returning a list.

### 2.2 `misspelledColor` has no effect on the underline

`setMisspelledColor()` stores the colour but never rebuilds the `errorFormat`
built in the constructor, and the constructor forces the default to `Qt::red`.
The rendered underline is therefore **always red**, whatever `misspelledColor`
reads back as (verified: setting green both before and after `document`, and
imperatively, still renders `#FF0000`). See §5 decision D1.

## 3. Frozen adapter interface

Provisional file `ui/compose/SpellcheckAdapter.qml`, created by S01 and always
loaded through a `Loader` so the `org.kde.sonnet` import stays optional. Names
below are frozen for S01–S03; a later change is a contract change, not a detail.

**Inputs**

| Property | Type | Meaning |
| --- | --- | --- |
| `document` | `QQuickTextDocument` | the editor's `textDocument`; `null` before the editor exists |
| `enabled` | `bool` | user setting; false clears underlines and queries |
| `language` | `string` | desired language, default `en_US` |
| `personalWords` | `list<string>` | app-owned words to treat as correct (see §4) |

**Outputs**

| Property | Type | Meaning |
| --- | --- | --- |
| `available` | `bool` | Sonnet loaded **and** the requested language is available |
| `loaded` | `bool` | the optional component instantiated (distinguishes "no Sonnet" from "no dictionary") |
| `status` | `string` | one of `ready`, `no-module`, `no-dictionary`, `disabled` for the setup explanation |

**Functions**

| Function | Returns | Notes |
| --- | --- | --- |
| `inspect(position)` | `{word, misspelled, suggestions}` | calls `suggestions(position, 5)`, then reads `wordUnderMouse`/`wordIsMisspelled`; **do not** infer "correct" from an empty list — a misspelled word can have no suggestions |
| `suggestionList(position)` | `list<string>` | at most five, matching `inspect` |
| `applyCorrection(position, replacement)` | `void` | the primed `suggestions`+`replaceWord` pair of §2.1; undo-safe |
| `ignoreForSession(word)` | `void` | `ignoreWord`; process-global session scope |
| `setPersonalWords(words)` | `void` | re-applies the app-owned list (see §4) |

**Position handling.** Positions are UTF-16 code-unit offsets into the same
`QQuickTextDocument` the editor uses, so a position taken from
`TextEdit.positionAt(x, y)` or `cursorPosition` is the same coordinate
`suggestions()` expects. The adapter never computes word bounds itself: the word
under a position and whether it is misspelled come from `wordUnderMouse` and
`wordIsMisspelled` after an `inspect()` call.

**Document lifecycle.** `document` may be `null` at construction (the editor is
created with the composer). The adapter binds `document` and re-applies
`enabled`, `language`, and `personalWords` whenever it changes; it must not
`rehighlight()` during the change itself.

## 4. Personal words and ignore scope

`addWordToDictionary` writes the user's global Hunspell dictionary, which S6
forbids ("persisted in private app settings rather than modifying global Sonnet
preferences"). **Frozen rule:** the application owns the personal word list and
persists it in its own settings; the adapter applies every personal word with
`ignoreWord`, which is session-only. Personal words therefore survive a restart
because the app re-applies them, and the user's global dictionary is never
touched. "Ignore for this session" and a personal word are the same mechanism
with different persistence. Both are process-global, which matches S6's
"current application process/session" wording and makes all composers agree.

## 5. Decisions (supervisor confirmed 2026-09-29)

**D1 — underline colour cannot come from the theme (S5).** S5 requires the
underline colour to come from a semantic theme role via `misspelledColor`. It
cannot: the property is inert (§2.2) and Qt renders `SingleUnderline` in the
format's colour, which is fixed red. Options: (a) accept the fixed red as a
functional affordance and record the deviation from the no-literal-colour rule;
(b) draw an own underline over the text (the plan warns against "hand-drawn
underlines" and a second engine); (c) accept red for v1 and revisit if Qt/Sonnet
exposes a working colour. Recommendation: **(a)** — it is Qt's own spell-check
affordance, not an app colour choice, and `tests/test_source.sh` only forbids
literal colours in app source, which this is not. **Decision: accept (a)** — the
underline stays Qt's fixed red for v1; revisit only if Qt/Sonnet exposes a
working colour.

**D2 — personal-word persistence (§4).** Confirm the app-owned-list model
(apply via `ignoreWord`) instead of `addWordToDictionary`, since the latter
writes the global dictionary. Recommendation: **confirm**. **Decision: confirmed**
— the app owns the personal list and applies it with `ignoreWord`; the global
dictionary is never written.

**D3 — correction path (§2.1).** Confirm relying on Sonnet's `replaceWord` with
the priming rule, rather than replacing text through the editor's own
`remove`/`insert`. Recommendation: **confirm**, because it is undo-safe and keeps
Sonnet's own word-trimming (leading/trailing apostrophes) consistent with the
suggestions it offered. If the supervisor prefers editor-level replacement, that
is a contract change to freeze here. **Decision: confirmed** — use Sonnet
`replaceWord` with the frozen priming rule.
